# Database migrations (Supabase SQL Editor)

Run **`../schema.txt`** first for a fresh database, then apply migrations below as needed for your environment.

| File | Purpose |
|------|---------|
| `migration-add-subtitle.sql` | Product subtitle field |
| `migration-add-related-products.sql` | Configurable related products |
| `migration-add-category-hierarchy.sql` | Category hierarchy |
| `migration-add-delivery-preferences.sql` | User delivery preferences |
| `migration-add-hero-image-focus-point.sql` | Hero image focus coordinates |
| `migration-add-product-awaitingrestock.sql` | Awaiting restock flag |
| `migration-add-product-isdisabled.sql` | Disable products |
| `migration-add-product-promodiscount.sql` | Product-level promo discount |
| `migration-add-super-promo.sql` | SUPER PROMO items table |
| `migration-add-testimonials.sql` | Testimonials |
| `migration-add-variant-promotional-price.sql` | Variant promotional price |
| `migration-admin-inventory-order-workflow.sql` | Admin inventory / order tracking views |
| `migration-create-favorite-products.sql` | Favorites |
| `migration-create-users-table.sql` | Storefront users |
| `migration-update-store-contact-email.sql` | Store contact email |

Copy each file’s contents into the Supabase SQL Editor and run once.
